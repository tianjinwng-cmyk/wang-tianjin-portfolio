# 🐾 Pet Tarot — AI-assisted Tarot Card Drawing App

An independently developed mobile application combining pet-themed tarot experiences, original visual design, and interactive user interfaces.

## 1. Project Overview

Pet Tarot is a personal mobile application inspired by the idea of combining tarot card experiences with pet companionship.

The project explores how AI tools can support the development process, from initial creative concepts and visual design to application implementation.

## 2. Key Features

- Pet-themed tarot card experience
- Interactive mobile user interface
- Original visual design concept
- Daily pet mood and fortune experience

## 3. My Contributions

Independently initiated and developed the project, with responsibilities including:

- **Product Concept:** Developed the initial product idea and creative direction.
- **Visual Design:** Created the visual concept for the tarot cards and application interface.
- **UI/UX Design:** Designed the application layout and interaction flow.
- **AI-assisted Development:** Used ChatGPT and Codex to assist with code generation, debugging, and development.
- **Integration & Testing:** Integrated code modules, resolved implementation issues, and built a functional application prototype.
